My Love — Birthday Website

Extract this folder, then open index.html in a modern browser. Keep the assets folder next to index.html; it contains both gallery videos, the smile-frame photo, cat images, and the background song.

Optimized for portrait phones: the photo fits within the available screen height without cropping, the video gallery scales to narrow screens, and layouts account for phone safe areas. The page allows pinch-to-zoom.

The song starts when the letter is opened. Use the top-right music control to mute or unmute. Gallery videos start muted and have their own controls.

The page loads GSAP and Google Fonts from public CDNs, so those features require an internet connection.
